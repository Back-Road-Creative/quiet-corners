# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub's report form:
<https://github.com/Back-Road-Creative/quiet-corners/security/advisories/new>
(the repository's **Security** tab, then **Report a vulnerability**).

Please do not open a public issue for a security problem: everyone can read it
before a fix is ready.

A useful report says what you found, how to reproduce it, and which commit you
tested.

## Supported versions

There are no releases. Fixes land on `main`, and only `main` is supported.
